Featured project

F1 News Hub

I built F1 News Hub to bring headlines from different Formula 1 news sites into one place. You can search for a story or filter by source, then head to the original site to read it.

Built with
Next.js and Tailwind CSS.
How it works
It collects the headlines and links back to the publishers. The full articles stay on their own sites.

Gaming & side projects

FS25 Discord Bot

I built a Discord bot to keep an eye on a Farming Simulator 25 server. It posts updates when the server goes online or offline, players join or leave, and things change on the farm.

  • Python
  • Discord
  • XML

It can flag low stock and new production pallets, too. Commands like /status, /players, and /production let you check what's happening from Discord.

This started as a bit of vibe coding with AI. I’ve kept working on it since, making changes and figuring things out along the way.

Raspberry Pi tinkering · Prototype

Fish tank monitor

A little experiment bringing together my interest in web development and Raspberry Pi. Fish Monitor is a React dashboard that gets temperature readings from my Pi REST API and shows them on a colour-coded gauge.

  • React
  • Node.js
  • Express
  • REST API

It's still a prototype: the API reads temperature data from a local file, and the pH gauge uses sample values. The two projects cover the dashboard and the API behind it.
